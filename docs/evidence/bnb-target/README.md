# Evidencia pública BSC

Las primeras observaciones sin trades son instantáneas anteriores. El resumen final es `verified-target-sample.json`: dos compras reales del target, sin venta capturada.

`quote-pair.json` contiene dos cotizaciones reales posteriores. No son ejecuciones ni una simulación que aplique nuestro BUY al estado antes de cotizar SELL.

`adapter-benchmark-summary.json` documenta un intento incompleto del adaptador completo. No reemplazar esa conclusión por el éxito posterior de llamadas directas al QuoterV2.

Los fixtures registran proveedor, recepción, solicitudes y respuestas. Metadatos consultados a latest no prueban por sí solos el estado histórico de cada pool. Las referencias /tmp describen rutas originales de captura; los archivos por nombre se incluyen aquí cuando corresponden.
